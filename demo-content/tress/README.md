# Tress demo store

Demo content for the Tress preset (primary industry: Beauty (hair care)). Generated by `scripts/build-demo-content.mjs`; change `scripts/src/demo-catalog.mjs` or `scripts/src/demo-pages.mjs` and run it again.

Every step below needs the owner's Shopify accounts, so each one is listed under "Owner actions" in `docs/progress.md`. Nothing here touches the ibBan store.

## Setup order

1. **Create the store** "Tress demo" from the Partner Dashboard (or on a plan that includes B2B, if wholesale mode should show). Store currency EUR.
2. **Password:** Online Store > Preferences > Password protection on, with the same password on all three demo stores.
3. **Payments:** Bogus Gateway (or Shopify Payments in test mode) only; turn every other payment method and express checkout off.
4. **Shipping and pickup:** one shipping zone for Spain and one for the rest of Europe; enable local pickup at the store's location so the product page shows pickup availability.
5. **Metafield definitions:** create the ones in `metafields.md`.
6. **Products:** import `products.csv` (Products > Import), then do the admin steps in `products.md` (category, unit prices, images, hair type).
7. **Collections and menus:** `collections.md`.
8. **Filters:** in the Shopify Search & Discovery app, add filters for availability, price, product type and tag, plus Hair type. The app is Shopify's own; confirm with Shopify that it is allowed on a demo store (owner review).
9. **Pages, blog, policies:** `pages.md`.
10. **Theme:** upload the Theme Store zip (`dist/weft-themestore.zip` from CI) to the demo store, choose the Tress style, then follow "Theme editor" in `pages.md`.
11. **B2B:** `b2b-setup.md` (company, test contact, catalog, wholesale-only products).
12. **Check:** browse as a guest and as the test contact; every home page section has content, no placeholder images remain, and checkout reaches the Bogus Gateway.
13. **Screenshots:** follow the shot list in `docs/theme-store-listing.md`.

## Files

| File | What it holds |
|---|---|
| `products.csv` | Shopify product CSV: products, variants, prices, stock, weights, SKUs, tags and the text metafields |
| `products.md` | Catalog overview and the settings the CSV can't carry |
| `metafields.md` | Metafield definitions and where the theme uses each one |
| `collections.md` | Smart collections and menus |
| `b2b-setup.md` | Company, test contact, catalog, price list, quantity rules, volume pricing, wholesale-only products |
| `pages.md` | Pages, blog articles, policies, finder answers and theme editor steps |
| `images.md` | Shot list with alt text, and the credits table |

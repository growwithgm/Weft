# Tress demo store: collections and menus

Create every collection as an automated (smart) collection with the conditions below, so new products join on their own. Add the collection images from `images.md`.

| Collection | Handle | Conditions | Description |
|---|---|---|---|
| Shampoo | `shampoo` | Type is equal to Shampoo | Cleansers for every hair type. |
| Conditioner | `conditioner` | Type is equal to Conditioner | Detangle and seal the cuticle. |
| Masks and treatments | `masks` | Type is equal to Mask, or Type is equal to Treatment | Weekly repair and scalp care. |
| Styling | `styling` | Type is equal to Styling | Define, protect and finish. |
| Color | `color` | Type is equal to Color | Permanent color for the salon. |
| Tools | `tools` | Type is equal to Tool | Combs and accessories. |
| Repair routine | `repair-routine` | Tag is equal to repair | Wash, condition, treat and style damaged hair. |

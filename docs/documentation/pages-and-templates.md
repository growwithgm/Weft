# Pages and templates

This page describes the page templates that come with Weft, and the blog, customer account, password, gift card and 404 templates.

## Assign a template to a page

1. In your Shopify admin, go to **Online Store > Pages**.
2. Open a page or click **Add page**.
3. In **Theme template**, choose the template.
4. Save, then open the page in the theme editor to edit its sections.

Each template starts with ready-made sections that you can change, remove or add to. Templates work in every style.

## Blog and blog posts

### Blog

The **Blog** section shows your blog's posts as cards with pagination.

| Setting | What it does |
|---|---|
| Show blog title, Description, Text alignment | The blog heading area. |
| Show tag filter | Links that show posts with a tag. |
| Posts per page, Columns on large screens | Grid layout. |
| Show the latest post larger | Features the newest post. |
| Show featured image, Image aspect ratio | Post images. |
| Show tags, excerpt, author, date and "Read more" | Details on each card. |

### Blog post

The **Blog post** section shows the featured image, title, author, date, tags, content, share links, links to the previous and next posts, and comments. Below it, the default template shows more posts with the **Blog posts** section.

| Setting | What it does |
|---|---|
| Show featured image, Featured image width | Full width, page width or text width. |
| Heading alignment | Start or center. |
| Show tags, author and date | Post details. |
| Show share links | X, Facebook and Pinterest. |
| Show links to the previous and next posts | Navigation between posts. |
| Comments per page | Comments are paginated. |

Comments show when you allow them for the blog in your Shopify admin. After a shopper posts a comment, the page shows Shopify's success, moderation or error message.

## Customer accounts

New customer accounts are Shopify's default. With them, the account icon in the header uses Shopify's account component, which shows sign in and the account menu on desktop and mobile. Choose the menu in the Header section's **Customer account menu** setting.

Weft also includes templates for classic customer accounts: login, create account, account with order history, order, addresses, activate account and reset password. They're used only when your store still uses classic accounts. Each template has a color scheme setting.

Wholesale buyers sign in the same way. See [Wholesale](wholesale.md).

## Password page

The password page shows while your store is password protected.

| Setting | What it does |
|---|---|
| Logo, Logo width | A logo for this page. Uses the theme logo when empty. |
| Heading, Text | Your message, for example "Opening soon". |
| Show email signup, Signup heading | An email signup form. |
| Show social media links | Links from Theme settings > Social media. |
| Show "Powered by Shopify" | The Shopify credit. |
| Color scheme | Page colors. |

The page also has the password form for you and anyone you share the password with.

## Gift card

The gift card page is what customers see when they open their gift card. It shows the card value, the balance when it has been used, the expiry date when there is one, the code with a copy button, a QR code, a **Shop now** button, an **Add to Apple Wallet** link when available, and a print button. Set a **Gift card image** in the Gift card section.

## 404 page

The 404 page shows when a page isn't found. It has a search field and a continue shopping button.

| Setting | What it does |
|---|---|
| Show the wholesale sign-in line | Adds "Wholesale customer? Sign in to see trade-only products" with a link to your wholesale sign-in page. It helps wholesale buyers who follow a link to a product that's only in your B2B catalog. Hidden for signed-in wholesale buyers. |

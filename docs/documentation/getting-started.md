# Getting started

This page walks you through adding Weft to your store, choosing a style and setting up the basics: logo, colors, fonts, menus and section groups.

## Add Weft to your store

1. In the Shopify Theme Store, open the Weft listing.
2. Pick the style you want: Weft, Tress or Balm. See [the three styles](index.md#the-three-styles).
3. Add the theme. It appears in your theme library under **Online Store > Themes**.
4. Click **Customize** to open the theme editor and set up the theme before you publish it.
5. When you're ready, publish the theme from your theme library.

You choose a style when you add the theme. To try a different style, add Weft again with that style. It's added to your theme library as a separate theme, so your current theme stays as it is.

## Where settings live

Weft has two kinds of settings:

- **Theme settings** apply to the whole store: colors, fonts, product cards, cart behavior, wholesale options and more. In the theme editor, open **Theme settings** from the sidebar. Every group is described in [Theme settings](theme-settings.md).
- **Section and block settings** apply to one section or block on one template. Click a section or block in the theme editor to see its settings.

Use the template selector at the top of the theme editor to switch between the home page, product pages, collection pages and other templates.

## Logo and favicon

1. Open **Theme settings > Logo and favicon**.
2. Upload your **Logo**. Logos of any shape work; set **Logo width on large screens** and **Logo width on mobile** so it fits your header.
3. Upload a **Favicon**. It's scaled down to 32 x 32px, so use a simple square image.

The password page can use its own logo. See [Pages and templates](pages-and-templates.md#password-page).

## Colors

Weft uses color schemes. A color scheme is a named set of colors that you apply to sections, blocks and overlays.

1. Open **Theme settings > Colors**.
2. Edit an existing scheme or add a new one. Each scheme sets these colors:

| Color | Used for |
|---|---|
| Background, Background gradient | Section background |
| Text, Headings, Secondary text | Body text, headings and lighter supporting text |
| Panels and image backgrounds | Cards, panels and the area behind images |
| Borders and dividers | Lines, input borders and dividers |
| Links | Text links |
| Primary button, Primary button text, Primary button hover | Main buttons such as Add to cart and Checkout |
| Secondary button, Secondary button text and border | Outline buttons |

3. In each section, pick a scheme with its **Color scheme** setting.
4. Set **Drawers and pop-ups** to the scheme used by the cart drawer, menus, quick add and other overlays.

The **Accents** colors in the same group set sale prices, rating stars, stock status, success, error and information messages. Status colors always appear together with a text label, so they don't carry meaning on their own. When you change colors, check that text stays easy to read against its background.

## Typography

Open **Theme settings > Typography**:

- **Headings**: font, heading size, and whether headings and subheadings are uppercase.
- **Body**: font and base size.
- **Navigation and buttons**: whether navigation uses the body font or the heading font, and whether button text is uppercase. Navigation uses one of your two fonts, so it doesn't load an extra font file.

Fonts come from Shopify's font library.

## Menus

Create menus in **Online Store > Navigation** in your Shopify admin, then connect them in the theme editor.

| Where | Setting | Default |
|---|---|---|
| Header | **Menu** in the Header section. Nested menu items become dropdowns. | Main menu |
| Header | **Quick links**: extra links after the main menu | None |
| Header | **Customer account menu**: links in the account menu | Customer account main menu |
| Footer | **Menu** blocks in the Footer section, and the **Secondary menu** setting for policy and legal links | Footer menu |

To turn a top-level menu item into a mega menu:

1. In the Header section, add a **Mega menu** block.
2. In **Menu item**, enter the title of the top-level menu item exactly as it appears in your menu.
3. Choose a **Style** (Columns, Buttons or Sidebar) and, if you want, images next to links, up to three promotion images and up to three link badges.

The header also has settings for a sticky header, logo position, menu alignment, where the mobile menu opens, country and language selectors in the mobile menu, search, and an optional call to action button.

## Section groups

Section groups hold sections that appear on every page. You edit them in the theme editor like any other section.

| Group | Sections |
|---|---|
| **Header** | Announcement bar and header |
| **Footer** | Footer. Add Menu, Text, image and socials, Email signup, Custom Liquid and app blocks. |
| **Overlays** | Cart drawer, Quick add, Search, Location switcher (wholesale buyers with several locations), Product compare and Pop-up. The pop-up is hidden until you turn it on. |

The announcement bar rotates up to three messages and can show two links and the country and language selectors on large screens. The footer can show country and language selectors, payment icons, a back to top link and "Powered by Shopify".

## Country and language selectors

The selectors show when your store sells in more than one country or has more than one published language. Set up countries in **Settings > Markets** and languages in **Settings > Languages** in your Shopify admin. Turn the selectors on or off in the announcement bar, the footer and the header's mobile menu.

## Social media and chat button

Add your social profile links in **Theme settings > Social media**. The links show in the footer and on the password page. To add a floating chat button, enter a wa.me link in the **WhatsApp** field and turn on **Show chat button**. The button opens WhatsApp with the current page link filled in.
